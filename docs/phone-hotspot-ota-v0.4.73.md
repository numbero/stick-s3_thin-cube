# 外部供电升级限制 v0.4.73

2026-10-24。用户决定不再支持纯电池发起固件升级，以避免小容量电池在写入和启动自检期间耗尽。

## 行为

- 手机页面允许连接热点、验证六位码和选择固件；开始升级必须接入 USB 电源，并满足既有保守 OTA 电量至少 50% 的要求。
- 页面显示供电状态，每两秒自动刷新。拔掉电源后禁用开始按钮，接回电源且条件满足时自动恢复，无需重新选文件或验证升级码。
- 使用 PM1 输入来源和 VIN 判断外部供电，沿用已有分类；不以 CHG_STAT 作为准入条件。电池充满但 USB 仍供电时可以升级；输入读取失败、未知或超过两秒未更新时均拒绝。
- 所有 HTTP OTA 共用设备端拦截，覆盖热点手机上传和 Mac Wi-Fi 上传。绕过或缓存旧页面也不能仅凭高电量开始；错误为 `external_power_required`。
- 设备在开始、A 确认、上传准入、每个数据块及启动分区切换前复查。确认或写入期间检测到外部电源丢失时，中止本次尝试，保留原启动分区。已打开的写入句柄由 worker 中止；`esp_ota_end` 已消耗的句柄不重复 abort。
- 电源状态由主循环读取 I2C 后一次性发布到 OTA 缓存，HTTP 任务在锁内读取；常规采样周期约一秒，检测并非物理插拔瞬间完成。切换启动分区后沿用原有 60 秒自检与 90 秒异常回滚，用户应保持供电直到绿色 `UPDATE COMPLETE`。
- 新限制在设备安装 v0.4.73 后生效；仅把新版文件放到手机，不会改变旧版设备所提供的页面和准入规则。

## 验证

- 真实 `ota.cpp` 的 61 个 ASan/UBSan host 场景通过，覆盖 100% 纯电池拒绝、未知/过期供电拒绝、满电外部供电允许、A 确认前拔线、上传前拔线、接收/写入/hash 校验/IDF 校验期间断开，以及原版本、镜像、取消、自检与回滚行为。
- 运行实际内嵌手机脚本，覆盖禁用按钮、未接电时不发升级请求、自动插拔刷新、满电且不充电仍可开始、50% 保守电量门槛、连接失败和设备拒绝后清除旧供电状态。
- 正式/Base 构建及完整本机回归通过（Swift 142 项、1 项原有跳过、0 失败），结果与产物保存在 `artifacts/phone-ota-v0.4.73/`。
- 本次未通过 USB 安装或执行物理插拔验收；新包供用户手动安装并验收。
