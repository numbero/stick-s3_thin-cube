# 热点开机入口大字倒计时 v0.4.68

2026-10-24。按用户确认的第二种预览“大字倒计时”实现，仅更新设备固件；Mac 保持 v0.4.38（build 59）。原热点与手机上传流程见 [v0.4.66](phone-hotspot-ota-v0.4.66.md)，上一版主题与闪烁修复、回滚取证见 [v0.4.67](phone-hotspot-ota-v0.4.67.md)。

## 布局

保持 135×240 竖屏与 `theme.h` 琥珀主题。顶部 PHONE UPDATE 和细分隔线固定；按住 A 时显示 HOLD A、中央 6× Font0 数字 `2 → 1`、SECONDS 与 Keep holding A。满两秒切换 READY、大号 A、RELEASE A 和 to open hotspot。底部细条表示按住两秒的进度，最下方始终显示 B: CANCEL。

首次绘制静态页；数字只在两秒变一秒时覆盖一次，达到两秒时才替换状态标签，进度条只增加填充像素，防止重新引入整屏清黑闪烁。使用既有 Font0 整数倍率，无额外启动画布。

按键规则保持原样：提前松开取消、满两秒松 A 进入热点、B 取消、按住十秒取消，开机 A+B 不进入维护。该进度仅表示进入热点的按住时间。

## 构建与实机验证

- 正式与 Base 环境构建通过；正式应用 1,845,408 字节，SHA-256 `d782c474beb7147db04db6dce5c291df51ebe5d1a7490e3d0ed281a75f7e9bc3`。
- 提取实际启动绘制和手势函数的 9 个 ASan/UBSan 场景通过，检查 1000 ms 数字切换、2000 ms 就绪、长按等待无重复提示绘制、增量进度和批准坐标；提前释放、B、A+B、十秒卡键及时间回绕行为保留。原维护策略测试通过。
- 手机页面 Node 检查使用最终 v0.4.68 镜像通过，包括完整镜像摘要、准入和既有上传协议。
- USB 烧录前读回两槽镜像与有效选择记录，备份 OTA 数据和 NVS；只写非活动 app0（`0x10000`）与第一选择扇区（`0xe000 / seq=5 / NEW`），写后 hash 校验通过。v0.4.67/app1 及其 `0xf000 / seq=4 / VALID` 记录保留，未写设置、bootloader 或分区表。
- 烧录后保持独立运行超过 90 秒，再读回确认 app0/v0.4.68 为 `seq=5 / VALID`、两槽镜像匹配发布包、两份选择记录 CRC 正确，原 v0.4.67 选择扇区逐字节不变。再次正常重启，日志显示 `clawd v0.4.68`、`ota state : valid`、`run app0`，BLE 控制恢复，IMU 持续更新。
- 新布局的物理 A 键观感待用户查看；本轮 USB 及自检验证不替代用户的显示验收。

构建、真实源码 host 检查、手机页检查与 USB 日志保存在 `artifacts/phone-ota-v0.4.68/`。
