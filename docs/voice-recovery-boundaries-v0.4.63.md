# 语音恢复边界修复：固件 v0.4.63 / Mac v0.4.36

2026-10-22。四条代码级复现对应的修复、完整回归、正式构建及本机应用/设备安装完成。实机验证倒立启动和离线倒立配对取消后重连自动传音通过。

## 行为与实现

| 原问题 | 修复 |
| --- | --- |
| 离线倒立时开启重新配对，取消/超时后重连仍待命 | 配对开放及解除配对仅暂停传音，保留姿态资格。原认证撤销和按键释放继续生效；只有新的合法音频对端就绪后才能恢复。先前的显式停止不会因配对结束被清除 |
| 手动传音时正在翻成倒立，点击停止后又自动开始 | `setPose(false)` 只在姿态健康且候选与稳定姿态一致时解除停止标记。形成倒立过程中的旧 FaceUp/Upright/Landscape 不再被当作新的退出 |
| 麦克风待就绪期间 IMU 失效，待启动请求仍开始传音 | `VoiceState::tick` 强制接收本次姿态健康参数，两次生产调用均用当前时钟检查 IMU，阻止绕过控制器的待启动提升。输入恢复后可继续启动；显式手动开始无需姿态，已建立语音的倾斜容错保留 |
| Mac 切换连接被拒绝，设备仍传音而 Mac 一直静音 | `LocalVoiceGate` 表达待设备停止的标记，与由 `switching/updating` 控制的临时拦截分开。连接切换只设置临时状态，拒绝/超时结束后自然放行，不要求设备额外发布停止快照。先前的显式停止仍需原待命确认 |

姿态阈值和确认时间、220 ms 倒立确认、正常退出回差、5/10/20 分钟休眠期限和线协议均不变。新会话仍更新 nonce、重建 A/B 上下文，旧边沿和手势不会跨恢复重放。电量校准在当前正式版本中仍关闭，未重新启用。
