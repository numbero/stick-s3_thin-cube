# 恢复出厂设置 v0.4.38

2026-10-18。固件 v0.4.38，Mac 帮助 v0.4.15（build 36），通信协议仍为 v1。

## 操作

按住侧面 B 键，单击电源/复位键开机或重启。松开 B 后，屏幕显示 `FACTORY RESET`，说明会删除全部设置且无法撤销。必须再单独短按 A 才开始清理；短按 B 取消并以原配置重新启动。开机按住的按键及其松键事件均被消费，同时点击 A/B 优先取消，不会误确认。

确认后显示 `RESETTING`，清理完成自动重启，回到 `CHOOSE CONNECTION`：A 蓝牙，B Wi-Fi 热点。需要重新配对和校准；Wi-Fi 热点密码在下次配网时重新生成。

## 清理范围与恢复

动态枚举并清空默认 NVS 分区中的全部配置命名空间，而不是维护容易遗漏的配置键清单。包括 ThinCube 授权、Wi-Fi 和旧版网络记录、SDK 保存的网络凭据、蓝牙绑定、配网热点密码、未完成网络事务、连接方式、校准、声音、亮度、语音和电源设置，以及旧 UiFlow 配置。板型、IMU 和射频的 NVS 缓存也清除，正常启动按库和 SDK 的流程重新检测或生成。固件、bootloader、分区表、OTA 记录及芯片 eFuse 身份不变。Mac 自身的设置和钥匙串不在设备恢复出厂的范围内。

仅在用户确认后持久写入 `tcsetup:factory` 标记。清理期间不开启无线服务，启动时也先检查标记，避免恢复未完成的配网事务。全部其他命名空间清理后，先清除其余 setup 键并提交，最后才删除恢复标记。清理或提交失败显示错误，B 重启后继续已确认的恢复；断电后重复执行可安全完成。

旧版 `tcsetup:reset` 标记仍按原来已经确认的“网络重设”范围完成，避免升级将旧事务扩展为清空校准和设置。新入口只创建完整出厂重置标记。取消及仅停留在确认页都不会创建标记或清理配置。
