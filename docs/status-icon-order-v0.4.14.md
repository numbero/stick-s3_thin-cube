# 状态栏图标顺序 v0.4.14

日期：2026-10-11。设备状态栏从右到左改为 Wi-Fi / 蓝牙、上位机连接、语音输入。待命时语音图标隐藏，空位留在左侧，无线信号图标保持在状态图标区最右侧。

原顺序从左到右为无线信号、上位机、语音。语音通常不显示，导致右端留空。修改 `drawStatusIcons` 中无线信号和语音图标的横坐标；上位机位置不动。竖屏主页与两个横屏游戏页面共用这个函数，沿用 12×12 图标槽位、16 px 间距和既有颜色、断开斜线、静音及异常提示规则。
