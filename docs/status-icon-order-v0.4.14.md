# 状态栏图标顺序 v0.4.14

日期：2026-10-11。设备状态栏从右到左改为 Wi-Fi / 蓝牙、上位机连接、语音输入。待命时语音图标隐藏，空位留在左侧，无线信号图标保持在状态图标区最右侧。

原顺序从左到右为无线信号、上位机、语音。语音通常不显示，导致右端留空。修改 `drawStatusIcons` 中无线信号和语音图标的横坐标；上位机位置不动。竖屏主页与两个横屏游戏页面共用这个函数，沿用 12×12 图标槽位、16 px 间距和既有颜色、断开斜线、静音及异常提示规则。

## 验证

- 既有 `ui_status_test.cpp` 以 C++11 编译运行通过，覆盖控制心跳、语音图标优先级及图标边界。
- 从修改前后的实际 `drawStatusIcons` 提取绘制函数，检查四个屏幕方向、Wi-Fi / BLE、连接 / 连接中 / 断开、上位机在线 / 离线及四种语音状态，共 192 种组合。所有图标在屏内，移动后各槽位像素与原对应槽位一致。
- release 构建、设备身份与 v1 协议检查、2 MiB 分区长度检查及镜像打包通过。静态 RAM 103,200 字节，Flash 1,705,373 字节；镜像 1,705,808 字节，SHA-256 为 `9738bca5a10ca18eea99871ec3cfe3543847b39551e4e1523cc48ca906e9378e`。
