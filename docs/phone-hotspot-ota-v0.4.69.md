# OTA 重启自检与完成提示 v0.4.69

2026-10-24。仅更新设备固件，Mac 保持已安装的 v0.4.38（build 59）。

## 行为

写入阶段的 `OTA_DONE` 现在显示琥珀色 `WRITTEN / Restarting to check / DO NOT RESTART`，只说明镜像校验与写入完成。手机在 HTTP 200 且 `{ok:true}` 后显示琥珀色“固件已写入，正在重启自检”，明确尚未确认完成，提醒保持供电、不要重启或插拔 USB。热点随设备重启断开，网页不再轮询或按计时宣告最终成功；上传到 100%、断线或请求失败也不被当作写入成功。

启动时只有 ESP-IDF 的 `PENDING_VERIFY` 激活设备“自检中／请勿重启”页。显示目标实际运行版本、已运行秒数与 60 秒参考进度；时间到达只显示 `CHECKING HEALTH...`，不会自行宣布成功。持续处理 IMU、输入采样与服务，保留原 60 秒健康门槛及 90 秒异常回滚。

只有 `esp_ota_mark_app_valid_cancel_rollback()` 实际成功，设备才显示绿色“升级完成”、运行版本和安全重启提示。完成页保持亮屏，短按 A/B 确认继续；从自检跨越到完成时仍按住的键或其释放点击不能误关闭该页。新准入的 OTA／热点操作可接管已完成提示。普通已确认版本的再次开机不虚构升级完成。

自检及结果页锁定竖屏、保持最低可读亮度，阻止静置／面朝下熄屏、自动关机、日常动画与姿态语音抢占。试启动忽略复位时残留 A/B 所对应的维护入口或恢复出厂确认，避免提示接管按键后卡在不健康的确认页；健康确认后的普通启动按键入口保持原规则。

中文仅保留 15 个 16×16 字形，共 480 B 原始字模；配套 efont BSD 版权许可位于固件目录 `COPYRIGHT-efont.txt`，源文件同时保留完整许可。

- 全部 CPU 本地检查通过，包括真实 OTA 源码 47 个 ASan/UBSan 场景、完成页新按键准入、手机写入 ACK 不提前成功，以及 142 项 Swift 检查（1 项既有跳过、0 失败）。最终镜像再次通过手机文件预检与摘要检查。

- USB 烧录核对目标 MAC `7c:e8:b1:e2:db:38`、双槽原镜像摘要和有效选择记录后，备份 OTA/NVS。仅写 app1 `0x210000` 与 `0xf000 / seq=6 / NEW`，写后 hash 校验通过，watchdog 复位。原 app0/v0.4.68/seq=5/VALID 保留。
