# 横屏探索甲板

实现版本：设备 v0.4.2；Mac 通信协议仍为 v1。2026-10-09 已编译、烧写并完成真机探索验收，用户确认“正常，符合预期”。

屏幕面向用户横持时，左右两个方向均显示 240×135 的探索甲板。正常竖持与倒立保留 135×240 布局。朝上平放不根据桌面内的转动猜方向，而是保留最近一次竖持/横持方向。

## 布局与角色

- 顶部：CLAWD // DECK、现有网络/上位机连接/传音状态图标、真实电量与充电状态。
- 左侧：约 89×70 像素的 Clawd、当前情绪、简洁落脚线。保持原几何比例，无嘴、无腮红、无手臂；眼神跟随探测器。持续传音时保留既有悬浮对讲机及红/绿灯语义。
- 右侧：点阵扫描区域和悬浮菱形探测器。少量离散粒子表达念力，不与身体画实体连线。
- 底部：待机显示 A:EXPLORE；活动探索显示 TILT:AIM HOLD A:EXIT，右侧保留本次开机发现次数。探索记录只在内存中保存，不增加 NVS 写入。

## 可玩行为

横屏待机时短按 A 进入探索，锁定当前显示方向并以当前握持角度为基准。轻轻左右倾斜，探测器在右侧瞄准目标；接近目标时轻微吸附，停留 250 ms 后显示绿色框，自动完成 1.1 秒扫描。Clawd 小跳回应，扫描环和进度条展开，依次发现芯片、晶体、轨道和信号四种像素物件。成功后结束本轮并恢复旋转；新的 A 短按开始下一轮，长按 A 1.2 秒可随时取消瞄准或扫描。

这些是本地探索演出，不代表设备发现真实网络、识别语音语义或完成转写。本地声音互动开启、未静音且醒着时，待机探测器高度可随真实音量响应；进入探索后固定瞄准高度，避免声音改变命中。静置休息后 A 首次按下只唤醒，再按才进入探索。活动探索暂停普通自动休息，强制进入独立流程时取消本轮。

## 与语音模式融合

横置被稳定识别后结束倒立姿态触发的语音，并释放快捷键。Mac 手动开始的持续会话保留，横置 A 只进行本地探索。显示方向已确认为横屏时即禁止 A 作为语音快捷键输入，防止显示确认与语音姿态确认的短暂时间差误发按键。再倒立时若 A 已按住，仍须松开后重新按下才发快捷键。

探索期间持续同步姿态基准，但不触发倒置传音；退出时等待当前姿态稳定后解除抑制，后续传音需要新的有效姿态转换。同一次长按取消及松手不发送快捷键。

## 旋转与内存

普通显示方向保持 90 ms 确认窗口；横置逻辑姿态使用 160 ms。探索锁定期间不累积旋转候选，退出后按当下方向重新开始确认。四方向使用最近角度路径，90° 过渡目标 120 ms、180° 目标 180 ms。过渡中间画面缩小时重排横竖布局，完成后回到 LCD 硬件旋转；两块约 64.8 KB 内部 RAM 画布预分配，横竖尺寸切换只重新绑定相同存储，避免反复分配与碎片化。动画逐帧运行，继续处理音频、控制租约与按键。

配网、配对与 OTA 保持完整竖屏流程，避免关键热点信息、PIN 或确认提示受横屏玩法影响。USB 调试可导出实际探索画布，拒绝配对窗口、旋转中和持续传音中的截屏；串口导出期间暂停本地采集，下一次设备循环按真实设置恢复。截图不保存音频。

## 探索交互规则

确认与实施日期：2026-10-09。探索期间通过 A 键主动锁定方向，配合轻微倾斜和目标吸附完成瞄准。普通模式保留约 90 ms 的方向确认窗口，不增加横竖屏切换延迟。

### 进入探索和恢复旋转

| 状态或操作 | 当前行为 |
| --- | --- |
| 普通横屏待机 | 保持快速自动旋转，等待用户主动进入探索。 |
| 稳定横屏时短按 A | 进入探索，锁定当前横屏方向，记录当前握持基准并出现待扫描目标。 |
| 探索中倾斜 | IMU 继续采集并控制探测器；不应用屏幕旋转，不由倾斜触发倒置传音或快捷键。 |
| 目标进入吸附范围并停留 | 显示绿色锁定框，随后自动扫描，无需第二次按 A。 |
| 扫描成功 | 展示发现结果，结束本轮探索并解除方向锁定。下一轮由新的 A 短按开始。 |
| 探索中长按 A | 持续 1.2 秒后取消瞄准或扫描，解除方向锁定。 |

探索中 A 长按只用于退出，不打开诊断页。同一次长按退出后等待松手，松手事件不再次进入探索，也不发送快捷键。退出时清除锁定期间的旋转候选和计时，只按当前握持方向重新判定，保留正常旋转速度。探索中形成的倒置姿态不作为退出后的待执行语音动作；姿态传音需要新的有效姿态转换。

探索区域底部显示“长按 A：退出”，不增加常驻状态栏图标。普通静置自动休息不打断正在进行的瞄准或扫描；进入配网、配对或 OTA 等独立流程时清理探索状态，避免方向锁遗留到其他页面。

### 轻微倾斜覆盖可玩区域

左右倾斜相对于进入探索时的握持基准计算。±3° 为忽略手抖的死区，±15° 覆盖探测器全部可达范围；输入平滑且在边界饱和，继续加大倾斜不会使探测器越界。这两个参数不影响普通模式的旋转判定。

目标中心和探测器可达范围共用边界，并按图形尺寸留出边距。首轮保持左右倾斜的一维瞄准，目标放在探测器可达的瞄准线上；道具的悬浮或音量起伏作为视觉效果，不使目标脱离可达范围，也不改变命中判定。

### 目标吸附和锁定反馈

距离均以 240×135 画布中的逻辑像素计算。进入目标中心 8 px 范围后，对显示位置作轻微吸附；保持 250 ms 后显示绿色锁定框并自动开始扫描。超出 10 px 时取消未完成的锁定计时，边缘微抖不会立即清零。锁定判断使用实际瞄准输入，避免吸附后的显示位置自行维持命中。

扫描开始后固定本次目标和瞄准位置，保留 1.1 秒扫描演出，完成后展示对应物件。扫描成功由目标锁定后的实际流程触发；仅按 A 并等待不会自动发现物件。Clawd 保留小跳与发现反馈。

## 编译、烧写与验收

所有 11 个固件 C++ 测试程序通过。其中 12 组探索、14 组显示/姿态方向、11 组姿态会话测试覆盖可达性、两种横屏方向、吸附迟滞、离开目标清零、计时回绕、长按事件归属、方向解锁和探索语音隔离。release 编译成功，RAM 102,856 / 327,680 字节，Flash 1,670,941 / 2,097,152 字节。

烧写前备份完整 8 MB Flash。此次仅写 app0（0x10000），未写 NVS、OTA 数据或分区表；1,671,376 字节镜像写入哈希校验通过。启动日志确认 v0.4.2、IMU 正常及原 BLE 连接恢复。

90 秒真机观察中，rot 3 完成两轮发现，rot 1 完成一轮发现，另有一轮长按取消。活动探索期间没有方向切换；其中扫描中逻辑姿态已变为 upright，仍保持原横屏直到发现完成，随后正常转回竖屏。成功和取消后方向确认均恢复，实际记录为 90–105 ms。用户对绿色锁定框、物件发现、探索中保持横屏和退出旋转回复“正常，符合预期”。

四种目标全部可达和 250 ms / 1.1 秒边界由单元测试验证；现场完成三次发现，未逐一量测角度与停留时长。此次未进行音频压力测试或 OTA 故障注入。
