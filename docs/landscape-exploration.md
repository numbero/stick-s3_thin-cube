# 横屏探索与念力接星

当前探索实现版本：设备 v0.4.22，支持二维姿态瞄准；Mac 通信协议仍为 v1。2026-10-10 的 v0.4.3 双横屏场景烧写记录见 `artifacts/landscape-games-v0.4.3/`，v0.4.2 和 v0.4.3 的历史验收保留在文末。v0.4.22 已通过 USB 烧写并确认正常启动；二维瞄准手感等待用户真机测试。

屏幕面向用户横持时，两个方向显示不同的 240×135 场景：**A 键在右（rotation 1）为目标探索，A 键在左（rotation 3）为念力接星**。正常竖持与倒立保留 135×240 布局。朝上平放不根据桌面内的转动猜方向，而是保留最近一次竖持/横持方向。游戏期间不切换场景，成功、到时或长按退出后才恢复方向判断。

## 目标探索：布局与角色

- 顶部：CLAWD // DECK、现有网络/上位机连接/传音状态图标、真实电量与充电状态。
- 左侧：约 89×70 像素的 Clawd、当前情绪、简洁落脚线。保持原几何比例，无嘴、无腮红、无手臂；眼神跟随探测器。持续传音时保留既有悬浮对讲机及红/绿灯语义。
- 右侧：点阵扫描区域和悬浮菱形探测器。少量离散粒子表达念力，不与身体画实体连线。
- 底部：待机显示 A:EXPLORE；活动探索显示 TILT:AIM HOLD A:EXIT，右侧保留本次开机发现次数。探索记录只在内存中保存，不增加 NVS 写入。

## 目标探索：可玩行为

横屏待机时短按 A 进入探索，锁定当前显示方向并以当前握持角度为基准。轻轻左右倾斜控制探测器横向移动，前后俯仰控制上下移动，在右侧二维区域瞄准不同高度的目标；接近目标时轻微吸附，停留 250 ms 后显示绿色框，自动完成 1.1 秒扫描。Clawd 小跳回应，扫描环和进度条展开，依次发现芯片、晶体、轨道和信号四种像素物件。成功后结束本轮并恢复旋转；新的 A 短按开始下一轮，长按 A 1.2 秒可随时取消瞄准或扫描。

这些是本地探索演出，不代表设备发现真实网络、识别语音语义或完成转写。本地声音互动开启、未静音且醒着时，待机探测器高度可随真实音量响应；进入探索后高度由姿态输入控制，声音与悬浮动画不再改变瞄准位置或命中。静置休息后 A 首次按下只唤醒，再按才进入探索。活动探索暂停普通自动休息，强制进入独立流程时取消本轮。

## 念力接星

短按 A 进入 20 秒的一轮游戏，锁定当前方向，并以进入时握持角度为基准。轻微左右倾斜使悬浮托盘在右侧接星区移动；接住时加一颗星并增加连击，Clawd 小跳回应，托盘短暂变绿。漏接仅清空当前连击并眨眼，本轮继续；结束显示本轮星数和最高连击。长按 A 1.2 秒可提前退出，短按 A 可开始下一轮。

- 顶部保留真实网络、上位机、语音、电量及充电图标；星数和连击是本地游戏数据。
- 左侧为较小的 Clawd，眼神随托盘移动；道具与身体之间只保留离散粒子，不新增手臂、嘴巴或实体连线。手动传音时保留缩小的念力对讲机。
- 右侧显示星数、剩余秒数、下落星星和 24 px 宽托盘；底部显示 `TILT:MOVE HOLD A:EXIT` 和方向锁状态。
- 共用探索的 ±3° 死区、±15° 全范围和 90 ms 输入平滑。托盘中心范围为 x=95–219，落星中心范围为 x=101–214；初始星位于中心 x=157。所有星位均可达。
- 落星速度从约 28 px/s 逐渐增加至 36 px/s；生成间隔从约 1.7 秒逐渐缩短至 1.2 秒。最多同时显示两颗，使用固定槽位，不动态分配或累积过期生成请求。接取判定含 4 px 容差，延迟帧跨过托盘也能判定。
- 每轮清空本轮分数、连击和最高连击；下一轮变换落星序列。计数只保存在内存，不增加 NVS 写入。静音时照常玩，休息时首次 A 仅唤醒。

## 与语音模式融合

横置被稳定识别后结束倒立姿态触发的语音，并释放快捷键。Mac 手动开始的持续会话保留，横置 A 用于当前本地游戏。显示方向已确认为横屏时即禁止 A 作为语音快捷键输入，防止显示确认与语音姿态确认的短暂时间差误发按键。再倒立时若 A 已按住，仍须松开后重新按下才发快捷键。

两种游戏期间均持续同步姿态基准，但不触发倒置传音；退出时等待当前姿态稳定后解除抑制，后续传音需要新的有效姿态转换。同一次长按取消及松手不发送快捷键。游戏结束时仍按住 A，也会消费此次按键，避免打开诊断或重复开始。

## 旋转与内存

普通显示方向保持 90 ms 确认窗口；横置逻辑姿态使用 160 ms。探索锁定期间不累积旋转候选，退出后按当下方向重新开始确认。四方向使用最近角度路径，90° 过渡目标 120 ms、180° 目标 180 ms。过渡中间画面缩小时重排横竖布局，完成后回到 LCD 硬件旋转；两块约 64.8 KB 内部 RAM 画布预分配，横竖尺寸切换只重新绑定相同存储，避免反复分配与碎片化。动画逐帧运行，继续处理音频、控制租约与按键。

配网、配对与 OTA 保持完整竖屏流程，避免关键热点信息、PIN 或确认提示受横屏玩法影响。长按 B 或 A+B 到达切换/重新配对提示时即退出游戏并使用完整竖屏流程。普通静置自动休息和摇晃情绪不打断活动游戏。USB 调试可导出实际横屏画布，拒绝配对窗口、旋转中和持续传音中的截屏；串口导出期间暂停本地采集，下一次设备循环按真实设置恢复。截图不保存音频。

## 探索交互规则

确认与实施日期：2026-10-09。探索期间通过 A 键主动锁定方向，配合轻微倾斜和目标吸附完成瞄准。普通模式保留约 90 ms 的方向确认窗口，不增加横竖屏切换延迟。

### 进入探索和恢复旋转

| 状态或操作 | 当前行为 |
| --- | --- |
| 普通横屏待机 | 保持快速自动旋转，等待用户主动进入探索。 |
| 稳定横屏时短按 A | 进入探索，锁定当前横屏方向，记录当前握持基准并出现待扫描目标。 |
| 探索中倾斜 | IMU 继续采集并控制探测器；不应用屏幕旋转，不由倾斜触发倒置传音或快捷键。 |
| 目标进入吸附范围并停留 | 显示绿色锁定框，随后自动扫描，无需第二次按 A。 |
| 扫描成功 | 展示发现结果，结束本轮探索并解除方向锁定。下一轮由新的 A 短按开始。 |
| 探索中长按 A | 持续 1.2 秒后取消瞄准或扫描，解除方向锁定。 |

探索中 A 长按只用于退出，不打开诊断页。同一次长按退出后等待松手，松手事件不再次进入探索，也不发送快捷键。退出时清除锁定期间的旋转候选和计时，只按当前握持方向重新判定，保留正常旋转速度。探索中形成的倒置姿态不作为退出后的待执行语音动作；姿态传音需要新的有效姿态转换。

探索区域底部显示“长按 A：退出”，不增加常驻状态栏图标。普通静置自动休息不打断正在进行的瞄准或扫描；进入配网、配对或 OTA 等独立流程时清理探索状态，避免方向锁遗留到其他页面。

### 轻微倾斜覆盖可玩区域

左右倾斜与前后俯仰都相对于进入探索时的握持基准计算。每轴 ±3° 为忽略手抖的死区，±15° 覆盖对应轴的全部可达范围，两轴使用相同的 90 ms 输入平滑；继续加大倾斜只在边界饱和，不会使探测器越界。这些参数不影响普通模式的旋转判定。朝屏幕向上倾斜时探测器上移，反向倾斜时下移；左右倾斜不会改变俯仰角，横屏方向翻转也不翻转屏幕法线。

探测器中心范围为 x=146–218、y=52–88；菱形与两枚离散粒子保持在右侧裁剪区域内。四种物件的目标中心分别为 (155,56.5)、(209,83.5)、(169.4,79)、(196.4,61)，绘制时取整；每个目标都在 ±15° 倾斜范围内可达，锁定框和发现物件也留有边距。每轮目标保持固定，发现后沿用原四种物件的循环顺序。

### 目标吸附和锁定反馈

距离均以 240×135 画布中的逻辑像素计算，使用横纵两轴的欧氏距离。进入目标中心半径 8 px 范围后，对显示位置的两轴作 45% 的轻微吸附；保持 250 ms 后显示绿色锁定框并自动开始扫描。距离超出 10 px 时取消未完成的锁定计时，边缘微抖不会立即清零。锁定判断使用实际瞄准输入，避免吸附后的显示位置自行维持命中。

扫描开始后固定本次目标和瞄准位置的两轴，保留 1.1 秒扫描演出，完成后展示对应物件。扫描成功由目标锁定后的实际流程触发；仅按 A 并等待不会自动发现物件。Clawd 保留小跳与发现反馈。
