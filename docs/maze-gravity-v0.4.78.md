# 迷宫重力方向修正 v0.4.78

日期：2026-10-26。用户试用 v0.4.77 后明确要求左右按低侧滚动：哪边压低，滚珠就向哪边滚。

## 修正

迷宫之前复用了探索、接星等玩法的横向姿态坐标。该坐标在 rotation 1 使用 `-ay`，rotation 3 使用 `+ay`，与滚珠所需的低侧方向相反。现在迷宫通过单独的 `mazeHorizontalDegrees` 将符号翻转：rotation 1 使用 `+ay`，rotation 3 使用 `-ay`。

转换在进入游戏、每次更新和恢复暂停前统一完成，握持基准始终使用同一个坐标定义。保留原左右 3° 死区、15° 满量和 90 ms 平滑；俯仰灵敏度、连续角度映射与贴墙修正沿用 v0.4.77。其他游戏继续使用各自原有坐标。

## 验证

新增验证以代表实际低侧的板载加速度样本开始，通过角度转换、握持基准、输入平滑和滚珠积分，检查最终的球位置和速度。

| 横屏方向 | 压低侧 | 样本 ax / ay | 期望与测试结果 |
| --- | --- | --- | --- |
| A 在右，rotation 1 | 右侧 | +cos(12°) / +sin(12°) | X 增加，vx 为正 |
| A 在右，rotation 1 | 左侧 | +cos(12°) / -sin(12°) | X 减少，vx 为负 |
| A 在左，rotation 3 | 右侧 | -cos(12°) / -sin(12°) | X 增加，vx 为正 |
| A 在左，rotation 3 | 左侧 | -cos(12°) / +sin(12°) | X 减少，vx 为负 |

同时验证两种加速度单位、无效传感器数据、跨横屏浏览后恢复同一局的位置/速度保留，以及新握持基准不改变原输入。现有 132 次俯仰姿态/单位检查和其他玩法测试继续通过。
