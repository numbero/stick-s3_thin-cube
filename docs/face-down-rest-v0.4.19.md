# 朝下息屏与翻起唤醒 v0.4.19

实施日期：2026-10-14。目标是把屏幕朝下放置作为主动在线休息动作，并在翻起后恢复使用。

## 行为

- 空闲时，已校准的屏幕朝下姿态与真实运动均稳定约 1.5 秒后进入休息：背光为 0，停止持续绘制，取消音效、停止麦克风与扬声器，复用现有音频芯片关断和在线省电路径。无需等待五分钟息屏。
- 保留 Wi-Fi / BLE 连接和控制心跳。启动健康确认完成后，沿用 CPU 160 MHz、闲置 IMU 最多 25 Hz、BLE 闲置连接间隔和状态发布节流；当前 SDK 没有新增 ESP Light-sleep。
- 翻起后，已确认的姿态离开朝下时恢复用户亮度与 240 MHz 性能。轻缓翻转即使加速度幅值始终接近 1g，也可通过姿态变化唤醒，不依赖拿起加速度事件。仍未确认的姿态退出、传感器噪声和短暂桌面碰撞保持息屏。唤醒确认通常使用已有的 moving 100 ms、朝上/横向 160 ms、竖向 220 ms 防抖，再受采样周期影响；这不是实测端到端时延。
- A/B/电源键与 Mac 手动开始语音在朝下时仍可唤醒。显式唤醒后，直到姿态确认离开朝下才重新允许朝下自动休息，避免下一轮循环就再次息屏；原三十秒视觉休息、五分钟息屏和十分钟纯电池关机仍按既有规则执行。
- 传音、游戏、配网、配对、OTA、模式切换、诊断、旋转和电池校准期间不进入朝下休息。开始上述任务或 IMU 失效/过期会退出朝下休息，保留操作界面。命令在 UI 更新后同一轮启动任务时，电源阶段再次检查保护条件。
- 朝下识别依赖既有屏幕朝上校准，未校准时不会猜测朝向。翻起后停止绘制和背光恢复由同一轮电源阶段更新，音频在恢复性能后走现有捕获准备及 BLE 快速连接门限。

## 与长时间待机的关系

朝下动作提前在线息屏，不修改深睡开关、纯电池限制、五分钟深睡门限、睡前 Mac 确认或 PM1/BMI270 唤醒事务。未开启深睡时，仍保留原十分钟纯电池关机；关机后需使用电源键。开启深睡时仍按原规则等待五分钟，拿起后的启动/重连与在线息屏唤醒是两种不同路径。

五/十分钟均从最后一次真实活动起算，朝下进入休息不把计时提前到门限；心跳不延长空闲窗口。持续运动会推迟入睡，朝下休息期间短暂运动只更新活动计时，不因旧的 pickup 事件或未确认的姿态而闪屏。

## 实现与验证

`FaceDownRestPolicy` 与实际 `PoseDetector`、`MotionActivity` 联合测试，覆盖完整确认时间、短暂扣下、轻缓翻转、桌面噪声及单次碰撞、忙碌取消、按键/Mac 覆盖、IMU 无效与过期、未校准、持续运动和时钟回绕。朝下事件复用姿态确认，不再等待第二段 1.5 秒，也不周期性重发睡眠事件。

云端 Linux ARM64 验证结果：

- `bash scripts/test-local.sh`：23 个 C++ 测试程序、5 个 Python 测试全部通过，其中新增策略包含 10 组场景。Linux 明确跳过需要 macOS 的 Swift 测试；本次未修改 Mac 上位机。
- `pio run -d firmware`：正式编译成功，固定依赖为 `espressif32@6.12.0`、M5Unified `8b63555` 和 M5GFX `0.2.32`。最终源码同步检查通过。
- `python3 scripts/package-firmware.py`：生成 `artifacts/thincube-v0.4.19.bin` 和 `artifacts/firmware-manifest.json`，型号/版本及 2 MiB 分区门限校验通过。镜像 1717952 字节，SHA-256 为 `f64091fa07dfc636d18646ce81b07a9959e8c9ad12e58a5d3bacf7cfdd9ab870`。
- 静态 RAM 使用 105568 / 327680 字节，Flash 使用 1717529 / 2097152 字节；构建、测试和打包没有访问设备。

此版本尚未烧录到设备，也未验证真机翻起响应、Wi-Fi/BLE 重复切换姿态、麦克风恢复或实际节能幅度。

## 真机验收

1. 完成原屏幕朝上校准，分别在 Wi-Fi/BLE、USB/电池供电下扣放：约 1.5 秒后背光关闭，日志应显示 `face_down 1 screen_off 1`；启动确认完成后观察在线省电读回。
2. 保持扣放，轻碰桌面不应闪屏；缓慢翻起、正常拿起应恢复保存亮度，重复扣放/翻起后仍可操作。
3. 息屏时按 A/B，或在 Mac 手动开始语音，应唤醒且不立即再睡回去；停止语音后翻起再扣放可重新进入休息。验证倒立语音、按键边沿和 BLE 音频开头不丢失。
4. OTA、配网、配对、模式切换、游戏与诊断期间扣放不能隐藏操作页面。未开启深睡时确认原五/十分钟规则；开启深睡时单独验证原五分钟入睡与运动唤醒。
