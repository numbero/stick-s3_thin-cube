# Clawd 心声与对话 v0.4.25

日期：2026-10-17。沿用已确认的英文像素终端风格，保留正常大小写、琥珀色和两行居中。替换日常主页原先的单行小字与 NOISE 条，传音时继续显示真实麦克风波形。

## 日常与互动

心声使用无框文字和两个轻微的像素点，Clawd 的视线略微偏向一侧。对话使用细长方框与指向主体的小尾巴，Clawd 看向用户，开始时短暂抬起一侧手臂。两种文字字号、颜色与行距一致；不加入字符表情、额外标签或持续闪烁光标。

文字在 y=176、188 两行显示，每行最多 20 个 ASCII 字符，使用原生 Font0 的 6×8 字格。装饰范围 y=163..202，不占连接说明（y=209）或底部按键区域。320 ms 入场按整行显现，避免逐字打印影响阅读。

日常池共有 384 条不重复组合：藏起小东西、物件借东西、遇见小东西三类共 336 条，加 48 条独立短句。RAM 中记录最近 64 条，避免连续三条使用同一模板、最近三个组合重复同一主题物件。每次恢复日常或真实互动后的心声会保持 12–20 秒；安静期间最多再换一次，不靠换字延长清醒时间。历史不跨重启保存。

六类真实事件各有三组关联的对话及事后心声：短按 A、拿起、从休息唤醒、接入 USB、游戏结束回竖屏、接星星后回竖屏。对话保持约 3.9 秒（含入场）后回到该事件的心声；对话全局冷却 12 秒，忙碌期间的事件直接丢弃，不排队补播。接入 USB 按实际外部供电变化判断，启动时已经插着 USB 不额外触发。

例如短按 A 可以得到：

> Hey, I was thinking! / Give me a second.

随后回到：

> ... That was nice. / Don't tell anyone.

## 现有体验与资源

文字层在设备命令、方向、休息策略及小剧场更新之后推进。传音、麦克风准备、倒立候选姿态、屏幕朝下候选姿态、旋转、横屏游戏、设置/配对/OTA、按键长按流程、诊断和小剧场均优先接管。离开后恢复一条日常心声，不补播被中断的对白。

原 A/B 短按、长按、组合键路由不变；首次按 A 唤醒仍只负责唤醒。游戏保留既有方向和输入，回到正常竖屏后才显示对应对白。传音仍使用原按需开麦、预热、姿态确认及重新触发逻辑。新功能不采音、不播放合成语音、不请求网络、不创建任务或动态分配文字缓冲，也不刷新活动时间。渐暗、30 秒视觉休息、屏幕朝下休息、五分钟待机及电池自动关机沿用原策略。

USB 本地诊断命令：`words think`、`words talk` 显示第一组短按 A 的两种状态；`words poke/pickup/wake/charge/game/catch` 定向展示相应对话；`words stop` 结束。预览保持八秒，但不唤醒、不阻止休息，受相同接管限制。已有 `screen` 命令可导出真实 LCD 像素。

## 构建与 USB 验证

28 个 C++ 测试程序、5 个电池校准 Python 测试通过；83 个 Swift 测试中首次跳过的固件身份检查，在提供最终应用镜像后单独通过。新增测试同时使用 C++11 编译运行，覆盖全部文案唯一性/长度、18 组对话及事后心声、冷却/不补播、所有接管条件、预览、6,000 次选词历史、时钟回绕、原电源期限及两种布局边界。源文案额外检查原始字符串长度，防止缓冲截断掩盖超宽内容。

release 构建静态 RAM 106,048 字节，Flash 1,740,897 字节；应用镜像 1,741,328 字节，SHA-256：`4d44996448808b8ec589c6e2969d2b73609c917dc3804341a3169c7b6bc7df85`。应用身份检查通过，符合原有协议及 2 MiB 槽位。

实际设备升级前运行 v0.4.23，分区表及 OTA 状态确认活动槽为 app0（0x10000）。已保存该槽的 2 MiB 回退镜像；USB 只写 app0，写入 hash 校验通过。未写引导程序、分区表、OTA 数据、NVS 或 app1。本次未重建 macOS 上位机。

已取得真实 135×240 LCD 的心声、对话和日常帧。两行大小写正确、居中且不遮挡连接与按键说明。连续观察超过启动 75 秒，无运行中重启、音频队列丢帧为 0；约 30 秒进入视觉休息，文字隐藏、麦克风停止采集，休息屏继续使用既有缓存。

用户完成实机操作并确认“全部正常”：短按 A 的对话与约四秒后的心声切换、倒立传音与翻回停止、两个横屏方向的游戏、朝下休息、轻碰保持息屏及翻起恢复。USB 日志同时记录倒立传音开始/结束、两侧横屏切换和对白回到相应心声。
