# 设备 UI v0.4.1 · 图标与主页

2026-10-09：用户已确认电池与状态栏设计，并要求开始实施；随后补充最新固件支持 BLE，需要对应连接模式图标。代码和独立构建已完成，实机 UI 验证待与正在运行的 BLE 联调会话协调。

## 状态栏

采用已确认的“连接清晰”布局。右侧三个固定位置为连接方式、Mac 控制连接、语音状态；图标 12×12 逻辑像素，间距 4px。待机时语音位置留空，其他图标不移动。

| 位置 | 图标与含义 |
| --- | --- |
| 连接方式 | 每次启动只使用 Wi-Fi 或 BLE，分别显示 Wi-Fi 或标准蓝牙符号。连接成功为绿色；Wi-Fi 初始连接或 BLE 物理链接建立、尚未完成安全握手时为琥珀色；断开为灰色斜杠。BLE 绿色以加密安全连接为准。 |
| Mac | 已认证控制通道收到有效 epoch 的心跳后为绿色。心跳超过 1 秒、网络断开、BLE 连接代次变化或重新配对时显示灰色斜杠。独立于 heartbeat 的音频 ready 标记。 |
| 语音 | 传音会话为绿色声波；静音为红色斜杠麦克风；Mac 已连接且允许语音、未休眠，但缺少校准、采集或音频准备时为琥珀色警示。三者互斥，静音优先，待机留空。按住/松开 A 不改变声波状态。 |

蓝牙与 Wi-Fi 使用相同位置和状态色，不能把 BLE 与 Wi-Fi 同时亮起表达为双通道在线。声波仅表达设备正在传音，不表示目标应用已识别完成；状态栏声波静态，主页较大的电平条反映实际麦克风电平。

## 页面

- 竖屏保留绿色电池百分比组件，以 CLAWD / VOICE 标题、状态、较大的像素角色和简短连接/语音说明为主。
- 移除重复 ENERGY 电量条及主页日志；待机保留 NOISE 条，传音显示麦克风电平和 A:KEY 提示。底部保留 A:PLAY / A:WAKE 与 B:MUTE。
- 横屏保留探索布局，使用同一套状态图标与电池，替换 MUTE / LIVE / WiFi / LOCAL 文字。
- 独立配网、PIN、切换与 OTA 页面保留。诊断页提供 IP 或 BLE MTU、IMU 和最近三条日志；空闲时单独长按 A 1.2 秒进入/退出，语音会话与 A+B 组合手势优先。USB debug 命令也可切换诊断页；配对、升级及传音时禁止该命令。

## 实现与验证

ui_status.h 提供图标绘制与语音显示规则；control_lease.h 维护独立控制连接租约。device.cpp 只新增只读 UI 状态与租约观察，不改变原音频就绪判断、传音、按键或配对协议。BLE 仅新增读取安全握手中状态的接口；BLE 联调会话同期的缓冲/PHY 修改仍保留在源码中，不归为本次 UI 修改。

11 个 C++ 测试程序已通过，包括原有电池抖动回放、语音/姿态/按键等回归，以及新增控制租约、音频未就绪时的 Mac 状态、计时回绕、图标边界与语音优先级检查。独立 PlatformIO 构建通过；交互预览已检查 BLE 传音、断开、静音三种状态，图标位置保持不变。

当前固件与 manifest 位于 artifacts/ui-status-v0.4.1/，独立构建目录避免与 BLE 联调共用 .pio/build。打包脚本新增可选 --image 与 --output-dir 参数，默认行为保持原样。本次没有重新构建 Mac 应用。

当前目录无 Git 元数据。修改前源文件快照保存在 artifacts/ui-status-v0.4.1/source-before-ui.tar.gz。初次构建因另一会话同时操作共用目录缺失 ui.cpp.o；后续改为独立构建并成功。实机烧录/截图结果完成后在此补充，尚不把编译或预览当作实机验收。
