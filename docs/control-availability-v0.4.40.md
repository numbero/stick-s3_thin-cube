# 关联控件的禁用规则：Mac v0.4.40（61）

2026-10-26。按功能开关和当前任务统一关联控件的可用状态，保留关闭前的设置值。设备固件继续使用 v0.4.80，本轮仅更新 Mac。

| 条件 | 交互 |
| --- | --- |
| 扬声器静音开启 | 音量滑块、自动保存提示与试听置灰；取消静音后恢复 |
| 正在向 Mac 传音 | 扬声器暂停播放，音量和试听不可操作；停止传音后按静音状态恢复 |
| 音量为 0% | 试听不可操作，音量滑块仍可调高，避免锁死在零音量 |
| 麦克风静音开启 | 输入增益及保存、声音互动、开始语音不可操作；取消静音后恢复 |
| 允许语音输入关闭 | 输入增益及保存、开始语音不可操作；独立的声音互动仍可设置 |
| 双敲关闭 | 日常和高级识别参数不可修改；开启开关、保存关闭状态、撤销和诊断维护仍可用 |
| 软件双敲识别关闭 | 软件识别专用参数不可修改；共享检测轴与原生报告参数继续可用 |
| 未连接、启动检查、连接切换、升级或校准进行中 | 相关设备设置不可修改；菜单栏和设置页使用相同条件 |

音量自动保存会在发送前重新检查当前状态和连接会话；静音、传音或其他不可编辑状态到来时，取消尚未发送的请求并恢复设备已确认的音量，避免禁用后发生延迟写入。已发送的请求遵循设备的正常确认过程。

原生滑块同步使用禁用状态，标题和数值也变灰；鼠标、键盘、辅助功能调整和保存按钮遵循同一规则。
