# 对讲机姿态切换容错 v0.4.39

日期：2026-10-18。状态：代码、固件回归与正式构建完成，尚未烧录设备或实机验收。本次没有修改或重新构建 macOS 上位机。

## 行为

保留既有“运动中 / Other”模糊状态以及正常竖持、横持、平放退出语音的交互。对讲机使用期间仅提高普通退出姿态的判定门槛，让自然握持与短暂倾斜继续保持传音。

| 参数 | 原值 | v0.4.39 对讲机退出 |
|---|---|---|
| 正常竖持的主轴分量 / 加速度模长 | > 0.82 | > 0.92，距目标轴约 23° 以内 |
| 横持的主轴分量 / 加速度模长 | > 0.82 | > 0.92 |
| 屏幕朝上的主轴分量 / 加速度模长 | > 0.90 | > 0.92 |
| 正常竖持确认 | 220 ms | 450 ms |
| 横持、屏幕朝上确认 | 160 ms | 450 ms |
| 倒立进入语音 | 220 ms | 保持原值 |
| 屏幕朝下识别 | 主轴 > 0.90，1500 ms | 保持原值 |

- 普通退出需要在同一个有效目标姿态内连续停留；回到模糊区、改变目标姿态、加速度失效或快速旋转会重新计时。加速度模长和角速度的有效范围保持原值。
- 放宽容错只作用于已建立倒立语音状态的传音会话或等待麦克风就绪的新手势。姿态变成 Other 后，语音状态仍保留退出保护，避免退回较低的普通门槛。没有会话时，桌面姿态、横屏界面和进入语音的响应时间沿用原规则。
- 语音仍有效时，屏幕保持当前方向；退出确认后再恢复原 90 ms 的旋转判定，避免画面提前转成横屏、将 A 键交给游戏并释放语音快捷键。A 在模糊过渡区仍可正常按下和松开。
- 停止、静音、断线等显式中止继续立即生效；恢复连接或取消静音后，仍保持倒立不会自动重开语音。进入语音前已按住 A，仍需先松开再按下。
- Mac 手动持续传音沿用原语义：退出倒立姿态释放快捷键，保留手动音频会话。

## 倒扣休息

屏幕朝下的角度、1500 ms 姿态确认与 `FaceDownRestPolicy` 均未修改。朝下姿态确认后结束姿态触发的语音，随后沿用现有的安静放置休息确认，关闭麦克风与背光、保持在线。翻起只唤醒到待机，新的倒立手势才能再次传音。

1500 ms 是朝下姿态识别门槛，不能当作从传音到息屏的完整时延：原休息策略在传音期间暂停安静放置计时，传音停止后需再确认 1500 ms 安静。联合策略测试以 40 ms 后的下一次采样开始休息确认，从首次朝下采样到休眠为 3040 ms；此值是测试序列时间，不是端到端实机测量。

## v0.4.40 进一步提高退出角度门槛

2026-10-18，按用户要求进一步扩大握持倾斜的容忍范围。普通退出姿态的主轴阈值由 0.92 提高到 0.966，目标轴的接受范围由约 23° 收紧到约 15°。以标准倒立握姿朝横持或屏幕朝上方向旋转为例，开始退出确认所需的倾斜幅度由约 67° 增加到 75°；翻回正常竖持则需更接近相反的竖直方向。

连续确认仍为 450 ms，运动模糊状态继续保持语音、A 键与屏幕方向。倒立进入的 220 ms、倒扣识别与安静放置休息流程均保留原参数。

角度回归覆盖所有普通退出目标及两种校准方向：20° 偏离（旧门槛内）和 15.5° 偏离保持语音；14.5° 偏离在 449 ms 时仍传音、450 ms 时退出。原四向倾斜、其他模式可达、倒扣休息、按键、停止与重连等场景继续纳入回归。

全部 34 个固件 C++ 测试程序与 PlatformIO 正式编译通过，日志保存在 `artifacts/walkie-pose-v0.4.40/tests.log` 和 `build.log`。打包生成 `artifacts/thincube-v0.4.40.bin`，身份与分区大小校验通过，长度及 SHA-256 见 `artifacts/firmware-manifest.json`。本次未烧录设备、未实机验收，也未修改或重新构建 Mac 上位机。
