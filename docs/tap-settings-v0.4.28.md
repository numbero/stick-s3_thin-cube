# 面向日常使用的敲击设置：Mac v0.4.28

持久化更新：固件 v0.4.57 / Mac v0.4.29 已改为直接保存到设备，重启后保留；恢复推荐需要明确确认并保存。当前行为见[设备保存](tap-persistence-v0.4.57.md)，下文保留 v0.4.28 的界面与验收记录。

入口为「按键 → 敲击识别 → 敲击设置…」。默认只展示开启双敲、敲击力度、双敲节奏、防误触以及简洁的检测状态和累计识别数。完整数值、原生参数、实验模式、撤销草稿和清零计数均收进默认折叠的「高级设置」。窗口沿用按键页的卡片底色、圆角和留白。

## 日常档位

| 调节项 | 档位 | 对应参数 |
| --- | --- | --- |
| 敲击力度 | 轻柔 / 适中 / 用力 | 软件冲击阈值 450 / 550 / 700 mg |
| 双敲节奏 | 快速 / 自然 / 稍慢 | 软件分类窗口 350 / 450 / 550 ms |
| 防误触 | 标准 | 旋转阈值 200°/s，旋转后抑制 300 ms，场景稳定 500 ms，按键后抑制 500 ms，冷却 600 ms |
| 防误触 | 加强 | 旋转阈值 150°/s，旋转后抑制 450 ms，场景稳定 700 ms，按键后抑制 700 ms，冷却 800 ms |

适中、自然、标准与之前校正的默认配置完全一致。其余档位是在默认值附近提供的有限调整范围，不代表已经分别经过自然握姿的准确率验证。界面说明力度降低可能增加误触，节奏放宽增加等待，加强防护可能漏掉晃动中的双敲。

单独选择某项只替换该项的参数；高级自定义值不被自动取整，无法匹配档位时显示「自定义」。使用原生检测或手持实验模式时，日常档位暂停编辑，保留高级编辑能力，并提供恢复推荐入口。「恢复推荐」只修改草稿并保留启用开关，仍需点击「应用到设备」。

## 生效与限制

通过原有认证接口发送完整配置，以请求 ID 和设备实际读回逐项确认成功后才显示已应用。后台读取不得覆盖较新的应用确认，也不覆盖未应用的草稿。清零计数保留未应用的调整。数值超界时提示并禁用应用。

设置期间双敲不发送快捷键，关闭窗口后恢复倒置对讲场景下的独立映射。固件仍为 v0.4.56；参数依然只对本次启动有效，窗口保存区及帮助中明确提示设备重启后恢复推荐值。未新增持久化、修改识别算法或改变快捷键绑定。

原始参数、传感器实现和实测记录见[双敲参数调试](double-tap-debug-v0.4.50.md)。
