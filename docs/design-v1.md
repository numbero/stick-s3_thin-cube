## 1. 一句话形态

一台能挂在身上、磁吸在金属面上的掌上字符终端，屏幕里住着一只由 ASCII 字符拼成的小生物。
设备平时深睡，你把它拿起来的那一刻它就醒了。

不追求功能数量，追求「它对你的动作有反应」这一条闭环成立。

## 2. 外设如何参与体验

| 外设 | 在体验里的角色 |
|---|---|
| LCD 135×240 ST7789P3 | 终端屏幕，字符栅格（见 §3） |
| BtnA（正面）/ BtnB（侧面） | 唯一的「精确」输入。A = 主要互动，B = 切页 / 长按睡眠 |
| BMI270 六轴 | 拿起→唤醒、摇晃→情绪、屏幕朝下→它睡、静置→发呆。也是唯一的自动唤醒源 |
| MEMS 麦克风 | 环境噪声 = 它听见的动静；吹气 / 说话有反应 |
| AW8737 + 喇叭 | 情绪叫声、事件提示音、短促 chiptune |
| 电池 + 充电状态 | 状态栏常显；插上 USB 触发「进食」表现 |
| M5PM1 | 背光分级关断、深睡、IMU 翻转唤醒、定时唤醒。让「一直带着」这件事在电量上成立 |
| 背面磁吸 | 它的物理「家」（冰箱 / 机箱 / 铁架） |
| Wi-Fi 2.4G（可选层） | NTP 校时 + 每天一条外部信息。未配网时静默降级，不影响任何主体功能 |
| Grove / Hat2-Bus | 预留：后续外接传感器可作为日志里的事件源 |
| IR | 按要求不做 |

## 3. 字符栅格与视觉规范（先定这个，它决定 UI 上限）

**字体与排版**

- 字体：设备端用 M5GFX 内置的 **FreeSans**（Helvetica 系现代无衬线，9/12/18/24pt 可选），
  不再是 Font0 点阵。屏幕上字号档位：状态栏 9.5、体征标签 7.5、数值 10、日志 9、页标题 13；
  小爪的独白用**斜体**（设备端对应 `FreeSansOblique9pt7b`），把「它说的话」和终端自己的文字区分开
- 因为是无衬线比例字宽，**不再有「字符网格」**：所有坐标按像素定位，行距 10px，左右边距 4px，
  长文本用 `measureText` 截断（浏览器里用 Helvetica Neue / Arial 近似 FreeSans 的字宽）

**布局（135×240，y 为文字顶部）**

```
y 4     BAT 78%                   22:04   ← 状态栏：左电量、右时间
y 16    ————————————————————————           ← 1px 分割线
y 19/29 MOOD value      NOISE ▮▮▮▯▯…      ← 左列标签+值，右列标签+分段条
y 41/51 ENERGY ▮▮▮▮▮▮▯▯…  LINK  wifi ok
y 62    pid 0x012a   up 00:12              ← 进程行（守护进程语汇）
y 78..148  小爪（66×52 单位 × 1.35 倍）
y 152   *hmm*                               ← 内心独白（斜体），随状态变
y 164   > ready                             ← 输入回显（终端提示符）
y 178   ————————————————
y 182.. 日志：6 行，按类型着色
```

**视觉**

配色以用户既有项目 `folotoy-vibecard/ui-mockup` 为基准，**主字色统一琥珀**，其他元素用语义色搭配：

| 用途 | 色值 |
|---|---|
| 主字色（正文、数值、提示符） | `#F8B000` 琥珀 |
| 高光（最新一条动态、强调） | `#FFC94D` |
| 次要（标签、历史日志行、装饰线） | `#B07C00` / 更暗用 `#6B4C00` |
| 选中行底色 | `#282010`（琥珀色调面板） |
| ok（开机自检、充电、联网） | `#3DDC97` |
| warn（噪声过大、电量偏低） | `#FFCC00` |
| err（不高兴、拔掉 USB） | `#FF3344` |
| 屏幕底色 | `#0D0D0D` |

小爪用**自己的一族 terracotta**，界面色（琥珀）不参与生物绘制：

| 用途 | 色值 |
|---|---|
| 身体 | `#D97757`（参考图原色） |
| 睡眠时的身体 | `#8A4A34` |
| 睡眠时的眼睛 | `#5A2F22` |
| 情绪符号 / 碎屑 | `#E8A184` |
| 眼睛 | `#140E0A` |
| 挑眉 | `#8C3A2A` |
| 腮红 | `rgba(255,176,146,.55)`，不高兴时 `rgba(206,74,54,.55)` |

日志按事件类型着色（沿用参照项目的 log-e 语义）：输入回显=琥珀、自检与好消息=绿、噪声与摇晃=黄、掉电与不高兴=红、普通事件=暗琥珀。

其他约定：分割线用 1px 直线；**不依赖字库制表符**；不用反白实心条，选中态用琥珀色调底 + 琥珀字；
电量与噪声用 10 段分段条（4px 段 + 1.5px 间隙），不用 `#` 字符（比例字宽下对不齐）。
扫描线效果**默认关闭**（大块实心图形上叠扫描线会有「灯芯绒」条纹感），需要 CRT 味道时按键打开。
本版没有做闪烁块光标，终端感由 `> ` 提示符行和日志时间戳承担。

中文：本版界面文字全部英文 / 数字，所以不涉及中文字库；日志文案保持英文。

## 4. 生物设定

**小爪（Clawd）—— 一只块状像素小生物，进程名 `clawd`。** 形象参考 Claude Code 的吉祥物，
几何取自用户既有项目 `vibe-notch` 里的 `ClaudeCrabIcon`，按 1:1 单位比例换算到我们的屏幕：

- 单位空间 66×52：身体 54×39、两侧 6×13 小触角、四条 6×13 腿（x = 6/18/42/54）、两颗 6×6.5 方眼睛
- 全部是直角矩形：不做圆角、不做抖动填充，保持像素质感
- 状态机：`SLEEP / IDLE / CURIOUS / EXCITED / UPSET / EATING / DIZZY`
- 运动语言：
  - IDLE 呼吸式上下浮动 ±1.5px，偶尔眨眼（眼睛压成一条横线）
  - CURIOUS 触角竖起 3 单位、身体朝倾斜方向偏、眼睛跟着倾斜移动
  - EXCITED 蹦跳 6px + 四条腿交替升降（走路动画）+ 周围冒 `* ! +`
  - UPSET 抖动 + 红色斜眉 + 腮红转红 + 红色 MOOD 值
  - EATING 身体上下小幅起伏 + 腿做咀嚼节奏 + 脚边掉碎屑 + 眼睛向下看
  - DIZZY 大幅乱晃 + `@`
  - SLEEP 眼睛闭成横线、不再浮动、右上角冒 `z`
- 我们自己加的可爱化处理：腮红方块、不高兴时的阶梯眉、走路腿动画 —— 参考图里没有这三样
- 日志行是它的独白，终端感主要来自这里：
  ```
  [12:04] poke!
  [12:07] too loud
  [12:11] nothing to do
  ```

**署名注意**：小爪是 Anthropic 的吉祥物形象。自用没问题；如果这份固件以后要公开，
需要注明形象来源并考虑授权。另外小爪整只用它自己的 terracotta 色族（身体、睡眠、符号、眉、腮红全在内），
琥珀只属于界面文字与控件，两者不混用；生物配色集中在 `CRABCOL` 一个常量里，想换色只改那一处。

## 6. 功耗策略

三级降级，每一级都能被 IMU 或按键打断：

1. 交互后 T1 秒无输入 → 关背光（L3B），生物继续跑在极低亮度 / 停帧
2. 再 T2 分钟无输入 → M5PM1 深睡，只保 L1 供电给 IMU（官方基线 52.47µA 级）
3. 唤醒源：IMU 翻转中断（PYG4）或按键

深睡实现要点（来自官方 M5PM1 文档）：

```cpp
pm1.setLdoEnable(true);
pm1.ldoSetPowerHold(true);
pm1.setLedEnLevel(true);
pm1.shutdown();
```

醒来后从 NVS 恢复「心情 / 年龄 / 上次互动时间」等持久状态。目标：随手放着能撑几天，而不是几小时。

## 7. 技术栈与实现分工

- 工具链：PlatformIO（本机已装，framework-espidf 已在）+ Arduino + M5Unified / M5GFX / M5PM1
- 帧动画：帧定义成字符串数组，画进 `LGFX_Sprite` 后整屏 `pushSprite`，避免闪烁
- 音频：麦克风采样沿用官方示例的 18kHz；频谱用 256 点实数 FFT（esp-dsp 或自写）
- 界面文字全 ASCII，因此不依赖中文字库，flash 占用低
- Wi-Fi 层：独立模块，未配置时直接跳过，任何代码路径都不得阻塞主循环

## 8. 待实机验证（这些不当结论写死）

1. `FreeSans` 9pt 在 1.14" 屏上的实际可读性 —— **2026-09-24 实测结论（两条坑，都已修）**：
   - **`textWidth()` 不可信**：设备上它报的宽度约为实际渲染的两倍，照它算右对齐与截断会全线偏移。
     改为**开机扫像素自标定**（画 10 个 `M` → 找最右亮像素 → 得真实步进与字高），
     布局一律按标定值算；135px 宽实际只放得下约 **15 个字符**（12px 无衬线），
     所以屏上文字要短，长文本一律以 `..` 收尾
   - **sprite 别放 PSRAM**：整屏 sprite 走 PSRAM + DMA 推屏时，变化区域会有缓存一致性导致的抖动闪烁
     （表现为小爪所在的矩形不断闪）。`setPsram(false)` 放内部 RAM 后消失（135×240×16bit = 65KB，够）
   - 小爪的缩放与居中要按当前 scale 现算，不能在缩放入口写死坐标
   - 日志区：去掉每行时间戳（占 8 字符）、只留 3 行短消息；带时间戳的完整日志走串口
2. efont 系列中英混排的栅格对齐（决定以后能不能上中文日志）
3. BMI270 三轴静态朝向（翻转判定阈值必须以实机读数为准，官方给的是示意图）
4. 麦克风基线噪声与「吹气」特征是否真的可分
5. 电池供电下喇叭安全音量（官方约束：≤75%，超出可能因瞬时功率重启）
6. M5PM1 深睡 + IMU 唤醒的实测电流与唤醒可靠性
7. BMI270 的 tap / orientation 硬件特性 —— M5Unified 只暴露 accel / gyro，
   要用得直接走 I2C，属非官方支持范围，验证通过才能进设计
8. Wi-Fi 打开时的功耗，以及配网信息存 NVS 后是否影响深睡

## 9. 交付节奏（三阶段，每阶段确认后再进下一阶段）

1. **本设计文档** — 你确认形态 / 生物设定 / 布局
2. **浏览器可点的高保真终端 Demo** — 已产出：`demo/index.html`（单文件，双击即开）。
   像素排版、状态栏、小爪动画、日志滚动；设备端目标字体 FreeSans，浏览器里用 Helvetica 近似；
   A/B 用键盘与屏下圆钮模拟，姿态 / 声音 / 电量走模拟输入。**已实测**：主界面、7 个状态表情、
   菜单页、关于页、自动睡眠与唤醒、页面在 1280×800 下完整可见。**未实测**：真机上的任何一项
   （见 §8），以及浏览器里的真实麦克风采集（Demo 里噪声是按键模拟）
3. **固件实现** — 顺序：字符 UI（FreeSans 排版）+ 按键 + 日志（真机可见）→ IMU → 麦克风 → 喇叭 → 电源
   与深睡 → Wi-Fi 可选层。每接一个外设都在真机上验一次，不做自动化测试
