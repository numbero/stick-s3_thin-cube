# Clawd 五段动画正式版 v0.4.12

日期：2026-10-11。用户确认 v0.4.11 实机 demo 的动画效果，并授权按计划正式实施。五段动画的实际绘制代码与确认版本逐字节一致，沿用原有页面布局、角色区域与刷新间隔。

## 正式播放

开机默认启用低频播放，无需打开诊断页：累计清醒 20–40 分钟产生首次机会，之后按同样间隔等待；滚动一小时清醒时间最多两段。维修工、星星借宿、贴纸冷却两小时；重力、黑洞冷却四小时，累计清醒一小时后才参加约 10% 的奇遇抽签。休眠不累计清醒时间，保留冷却与预算。

仅在正常竖屏主页、安静至少 12 秒、IMU 可靠且稳定至少 3 秒、电量有效，并能在原休眠期限前完整演完时开始。候选不可用或期限不足即跳过，5–10 分钟后再产生机会。原有操作、传音、运动、游戏、流程、断线、电源及睡眠状态优先，取消后不补播，不延长亮屏。

诊断预览保留：正常竖放、停止传音，长按 A 约 1.2 秒进入；短按 A 循环播放五段，长按 A 返回日常。诊断期间保持清醒，观看后需退出，自动播放才会恢复。完整片段、时长及安全规则见 [首版实现与操作](clawd-stories-v0.4.11.md)。

## 收尾修正

- 每个安全播放机会只抽签一次。原来日常片段都在冷却时会在后续主循环重新抽签，导致奇遇概率升高；现在候选不可用就丢弃本次机会。近期互动只调整同类权重，不改变奇遇抽签比例。
- Mac 连接恢复以及进入/退出诊断均重置独立的安静等待，退出诊断也清理旧选片提示。该等待不修改原休眠时钟。
- 自然横屏返回竖屏的情境提示在真实旋转完成后记录，避免旋转中的忙碌处理提前清除；强制流程页面转竖屏不产生这一提示。
- USB 检查脚本从当前 PlatformIO 配置识别版本，可通过 `--version` 指定旧版本，继续共用诊断预览入口。

## 验证范围

17 个固件 C++11 测试程序通过。新增回归覆盖三段日常内容同时冷却时禁止逐帧重抽签、休眠余量不足时丢弃机会，以及 20,000 次确定性选片中情境权重和奇遇类别比例的隔离；原十小时调度模拟与 1,565 帧实际绘制检查继续通过。

release 构建的静态 RAM 为 103,120 字节，Flash 为 1,690,577 字节；应用镜像为 1,691,008 字节，仍在 2 MiB 分区内。备份、正式镜像清单、源码快照、编译/测试/烧录与实机结果保存在 `artifacts/clawd-stories-v0.4.12/`，最终 SHA-256 和现场结果以其中 `validation.json` 为准。

完整 8 MiB 更新前备份已校验，旧 app1 与 v0.4.11 镜像一致；只写 app1（0x210000），写入 hash 验证通过。v0.4.12 五段再次完整实机播放并导出 LCD 关键帧，退出诊断后持续运行至启动 65 秒；最大绘制耗时 20.3 ms、音频队列丢帧为 0，原配对与 Mac Wi-Fi 控制连接保留。设备已结束定向预览，回到正常使用。

低频首播、滚动预算和冷却由时间模拟验证；未进行小时级实机等待或音频压力测试。实机逐段定向播放与正常启动验证不等同于所有真实运动/传音交叉场景。本轮只完成五段动画及其调度，上位机保持 v0.4.6。
