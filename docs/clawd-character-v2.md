# Clawd 角色与动作规范 v2

日期：2026-10-07

状态：角色设定与念力对讲机动作已由用户锁定；本规范已接入 v0.3 固件源码并通过编译，尚未刷机验证动作观感。

## 已锁定的角色设定

- 项目和 Mac 上位机名称为 ThinCube；角色名为 Clawd（小爪）。
- Clawd 是活泼、好奇、有探索精神和勇气的极客。动作体现主动观察、利落回应和快速恢复，保留眨眼、小跳和一点淘气；“酷”来自行动和判断。
- Clawd 没有嘴巴，不添加张嘴、咀嚼或说话口型。
- 移除脸上两块腮红，所有情绪状态均不绘制腮红。
- 保留现有 66×52 单位的几何比例：54×39 身体、两侧触角、四条短腿、两颗方眼。
- 不新增手臂或手掌，不用触角握持物品。情绪依靠眼神、眨眼、阶梯眉、触角、身体位移和四脚节奏表达。
- Clawd 具有念力，物品通过悬浮、位移、少量像素粒子表现受控。物品与身体之间留有明确间隙，不画实体连接。
- 身体保留 terracotta 色族，界面保留琥珀色；维持直角像素轮廓，不做嘴部、不大幅拉伸身体。

## 已锁定：语音模式与念力对讲机

以对话中最后确认的 `thin-cube-voice-gesture.html` 行为为准：

1. 设备上下倒置，屏幕仍面向用户；姿态确认和音频就绪后，对讲机被念力唤起并悬浮在 Clawd 身侧。
2. A 按下时保持用户配置的快捷键，对讲机平滑浮到脸侧，Clawd 看向它，触角微竖；通过身体和道具微动回应音量。
3. A 松开时释放快捷键，对讲机缓缓降回身侧。会话仍持续传音，LIVE 及音量条继续反映真实状态。
4. 静音或退出时用念力收回对讲机；静音真正停止麦克风采集，也停止声音驱动的动作。
5. 不以这些动画宣称第三方已开始识别、提交成功或完成转写。

对讲机指示灯按最新设定锁定为：普通待命时红色（`#FF4D4F`），A 按住传话时绿色（`#3DDC97`），松开后恢复红色。灯色表示传话快捷键的状态；实际音频会话仍以 LIVE 标识为准。

已确认的念力对讲机动作、按键与传音语义保持不变；角色外观按最新设定移除腮红。新的动作合集包含同一念力对讲机动作作为风格参照。

## 其他动作的优化方案

位移按设备屏幕像素描述；网页预览放大显示，最终幅度需要真机观感确认。常态位移约 1–2 px，事件跳跃上限约 4 px；短事件结束后自然回落。

| 动作 | 表现 | 触发及边界 |
|---|---|---|
| 待机观察 IDLE | 轻微呼吸、偶尔眨眼、左右观察，触角随注意方向微动 | 本地正常待机；不持续大幅摆动 |
| 好奇 CURIOUS | 眼睛先锁定目标，再主动向动静方向探身，两侧触角先后竖起，停顿后回正 | 拿起或有效声音活动；声音幅度只代表活动，不宣称识别了语义 |
| 开心 EXCITED | 先侧目回应，再预备、利落跃起一次；落地小回弹、两颗短暂火花，最后落稳 | 本地 A 轻戳等互动；不因每个音频帧重复触发 |
| 不悦 UPSET | 站稳、轻挑一边阶梯眉、直视片刻，再放松回正 | 既有情绪事件；表达边界，避免持续抖动与闪屏 |
| 晕乎 DIZZY | 短暂重心失衡、触角不同步，两颗琥珀像素星在头顶绕行，后方沿椭圆轨道带渐淡短拖线；恢复前星星与拖线一起淡出，约两秒内稳住，眨眼后继续观察 | 明确摇晃事件；不把倒置进入语音误当作摇晃，实际传音时收起眩晕星星 |
| 念力充能 CHARGING | 三枚能量方块先在身侧列队，再依次悬浮到身体边缘消失，视线跟随 | 仅实际正在充电时播放；满电或停止充电立即停止，不以接线本身判断 |
| 睡眠 SLEEP | 最后看一眼，闭眼、四脚略收、触角放低、身体静置，道具收好 | 停止麦克风和声音反应；不能通过声音唤醒 |
| 醒来 WAKE | 一只眼先探看，迅速睁开双眼、站直、抬触角；左右扫视后主动向前探 | 按键或拿起唤醒；不自动恢复先前 Mac 音频会话 |

原 EATING 的“咀嚼、碎屑、进嘴”设定废止。固件接入时应使用 CHARGING 名称，或先保留旧枚举并明确它仅为兼容标识，不再表达吃东西。

v0.3 固件已移除腮红和旧吃东西动作，使用 CHARGING 与 WAKE 状态，并接入念力对讲机。动作幅度、道具位置和音量响应仍需真机确认。

## 横屏双场景（v0.4.3）

A 键在右时为目标探索：左侧放大 Clawd，右侧出现悬浮探测器；短按 A 锁定方向并进入瞄准，轻微左右倾斜使探测器移动，Clawd 视线跟随。靠近目标并停留后显示绿色框，Clawd 小跳并发动念力扫描，依次发现芯片、晶体、轨道与信号像素物件。

A 键在左时为念力接星：Clawd 缩小位于左侧，用念力控制右侧的悬浮托盘。短按 A 开始 20 秒游戏，轻微倾斜接住落星；接住时小跳、托盘短暂变绿并增加连击，漏接时眨眼并清空连击，继续本轮。结束展示本轮星数与最高连击。

两侧均保留无手臂、无实体连线、无嘴和腮红的角色设定，物品与身体间只有离散粒子。活动游戏暂停普通自动休息和摇晃情绪；长按 A 1.2 秒退出，结束后恢复快速旋转。休息时 A 先唤醒，再按开始。探索待机可响应本地声音，活动瞄准和接星命中不受声音影响。

横置结束姿态语音；Mac 手动会话可继续，Clawd 保留念力对讲机，横置 A 用于当前游戏且不发送快捷键。完整布局、参数和验收见 [横屏玩法](landscape-exploration.md)。

## 组合与状态原则

- 情绪是底层，真实音频/网络/电源状态单独维护；声音动作是轻量叠加，不反复重置情绪。
- 声音互动关闭、静音、视觉睡眠和硬件深睡分别处理。视觉睡眠不等于当前已实现硬件深睡。
- 静音可保留按键和姿态反馈，但不得响应麦克风声音；睡眠不保留持续道具动画。真正硬件深睡时停止绘制。
- 充电与语音同时发生时保留念力对讲机，仅由状态栏标注充电，不让两个道具演出争抢画面。
- 配网、配对、OTA 优先显示实际流程；道具不遮住确认按钮、进度和错误信息。
- 动作合集中的声音、充电、LIVE、睡眠均为模拟事件，不连接真实麦克风、不发送键盘事件，也不控制设备电源。

### 动作音效（v0.3.9）

Clawd 用短电子音表达行动意图：醒来为两段上扬音，A 互动为轻快折返音，念力扫描为扫频，发现物件为三段确认音；好奇为短上扬音，晕眩为下滑折返，入睡为轻短降调。每次约 90–260 ms，使用淡入淡出，无说话、嘴型或婴儿化叫声。平时保持安静，不为眨眼或每次旋转鸣叫；语音输入时专注传话并让出全部音频通路。用户可独立静音音效。
