# 常态环境声纹与即时动作 v0.4.34

日期：2026-10-17。按用户最终决定，移除学节奏功能，改为竖屏右上角常态声纹，并加入 Clawd 对当前声音的即时动作。

## 行为

开启上位机“声音互动”后，只要设备醒着且处于正常竖屏主界面，就持续使用真实环境音量驱动七条短声纹。安静时保留低幅琥珀色形状，轻声、说话和较响的声音按强度舒展，快速升起、平缓回落；不使用假声谱或循环呼吸动画。每次声音都可以立即响应，不存在一次互动结束后退出、十秒窗口、三十秒冷却或必须重新拨动开关的限制。

Clawd 对较轻声音轻抬一侧小手、眼神望过来；声音较大时眼睛稍睁大；突发较响声音会轻轻后缩并短暂眯眼，随后恢复。突发反应约 420 毫秒、至少间隔 3.5 秒，避免嘈杂环境反复受惊。普通声纹和轻微动作在此间仍会随声音变化。说话、光点、兴奋、晃晕、睡眠和唤醒动画保留原有表现优先级。

已删除节拍识别策略、节拍时间和强度数组、计数标记、模仿动作与 USB 节奏演示入口。声音不再触发 `Did I get it?`、`One more time?`、单拍对话或节奏心声；正常心声、对话、A 键光点及两向横屏游戏保留。

## 采音与电源

开启环境感知时需要保持麦克风采音；关闭“声音互动”或麦克风静音后，环境采音停止，对讲仍按既有权限和姿态按需开麦。朝下休息、正常休息、游戏、光点、设置、更新和自身音效会让环境采音暂让，回到可用主界面后自动恢复，不依赖开关边沿或拿起事件。自身音效结束后保留短暂避让，再忽略开麦后的 200 毫秒瞬态。

本地声纹仅使用增益前 RMS 的当前幅度、平滑包络和一个短暂反射状态，不保存声音、不识别语音、不记录或回放节奏，不上传环境音频。只有既有明确对讲状态才走网络音频路径。声音不会刷新任何休息、渐暗或关屏期限；安静放置照常休息并关闭音频芯片。不声称开启环境采音本身改善续航。
